# AVX ApproxExp Notes

The optional AVX2 and AVX-512 IFMA ApproxExp kernels replace the scalar sampler exponentiation in opt-in builds while preserving the configured relative-error target. Their constants are generated by `tools/avxexp/gen_avxexp_consts.py` and `tools/avxexp/gen_avxexp_ifma_consts.py`.

The AVX2 variant uses a binary64 polynomial/table kernel. The AVX-512 IFMA variant uses a Q51 integer polynomial/table kernel with IFMA multiplication. Both are checked by `make check-consts` and have separate opt-in KAT files because they intentionally change sampler accept/reject decisions relative to the default integer path.
